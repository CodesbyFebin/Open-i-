# What Is an Agent Harness?

An **agent harness** is the software layer that turns a language model into a reliable agent.

The model is the component that generates text, plans, and tool calls. The harness is everything around it: the loop, the tools, the memory, the context manager, the permission gates, the audit log, and the verification step.

> **Agent = Model + Harness**

Without a harness, a model can only talk. With a harness, it can act, remember, coordinate, and be held accountable.

Open •i• is an open Agent Harness that also includes a full Agent Development Environment so you can run, monitor, and steer fleets of agents under your control.
