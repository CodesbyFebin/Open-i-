# Architecture Overview

Open •i• is organized into three planes:

1. **Experience Plane** — workspace, worktrees, any CLI agent, mobile companion, Design Mode.
2. **Harness Plane** — swarms, vector memory, self-learning, federation, MCP tools, audit.
3. **Control Plane** — unified cockpit, hybrid modes, observability, permissions, evidence.

Design principles: Agent = Model + Harness; isolation by default; memory is first-class; evidence over trust; any agent; ownable.
